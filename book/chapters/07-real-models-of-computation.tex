\chapter{Real Models of Computation}
\label{ch:real-models}

Every algorithms course quietly assumes a model of computation and then never
mentions it again. This chapter takes the question seriously. Comparing the word
RAM with the Turing machine already shows that the choice matters; the real RAM,
the model computational geometry actually uses, turns out to be strictly more
powerful in a way that is both useful and slightly alarming.

\section*{Learning goals}
\addcontentsline{toc}{section}{Learning goals}

After this chapter you should be able to:
\begin{itemize}[leftmargin=*]
  \item explain informally what a program on a word RAM is;
  \item explain informally what a Turing machine is;
  \item compare the two models and name advantages and disadvantages of each;
  \item explain the real RAM, and give both a motivation for and concerns about the model;
  \item compute $k!$ in $O(\log^2 k)$ time on a real RAM with rounding;
  \item compute $\gcd(a,b)$ in $O(\min\{\log a, \log b\})$ time on a real RAM with rounding;
  \item find a factor of a number in polynomial time on a real RAM with rounding;
  \item define straight line programs and \textsc{PosSLP}, and prove $\mathrm{P}^{\textsc{PosSLP}} = \mathrm{P}_{\R}$.
\end{itemize}
