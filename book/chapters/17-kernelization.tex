\chapter{Kernelization}
\label{ch:kernelization}

Kernelization is preprocessing with a guarantee. We already saw a quadratic
kernel for \lang{Vertex Cover}; here we push it to linear using linear
programming, develop the general tools, and then show that for some problems no
polynomial kernel exists at all.

\section*{Learning goals}
\addcontentsline{toc}{section}{Learning goals}

After this chapter you should be able to:
\begin{itemize}[leftmargin=*]
  \item define \lang{Integer Linear Programming} and encode \lang{Vertex Cover} as an ILP;
  \item prove that the LP relaxation of \lang{Vertex Cover} is half-integral;
  \item prove the Nemhauser--Trotter theorem and derive a linear kernel for \lang{Vertex Cover};
  \item use crown decompositions and the sunflower lemma to obtain kernels;
  \item explain how composition arguments rule out polynomial kernels.
\end{itemize}
