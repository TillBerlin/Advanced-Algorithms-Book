\chapter{Minimum Cost Flow}
\label{ch:min-cost-flow}

Adding costs to arcs turns maximum flow into a genuinely more expressive
modelling language: assignment, transportation, scheduling and inventory
problems are all minimum cost flow problems in disguise. We prove the optimality
criteria that make the algorithms work, and then spend most of the chapter on
modelling.

\section*{Learning goals}
\addcontentsline{toc}{section}{Learning goals}

After this chapter you should be able to:
\begin{itemize}[leftmargin=*]
  \item define the minimum cost flow problem and its standard special cases;
  \item state and prove the negative cycle optimality condition;
  \item state the reduced cost optimality condition and relate it to LP duality;
  \item analyse cycle cancelling and successive shortest paths;
  \item model an application as a minimum cost flow problem and argue that the model is correct.
\end{itemize}
