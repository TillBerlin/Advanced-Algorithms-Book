\chapter{The Existential Theory of the Reals}
\label{ch:etr}

A striking number of natural problems --- in geometry, in graph drawing, in game
theory, in machine learning --- are not known to be in \textbf{NP}, and the
obstruction is always the same: a solution is a tuple of real numbers that may
need exponentially many bits to write down. The class $\ER$ is the right home
for these problems.

\section*{Learning goals}
\addcontentsline{toc}{section}{Learning goals}

After this chapter you should be able to:
\begin{itemize}[leftmargin=*]
  \item define \ETR{} and the class $\ER$;
  \item give the machine-model description of $\ER$ and sketch its equivalence with the logic-based definition;
  \item prove that $\mathrm{NP} \subseteq \ER$;
  \item define order types and the order type problem, and motivate their study;
  \item define \textsc{ETR-AM} and prove that it is $\ER$-complete;
  \item prove $\ER$-completeness of the partial order type problem.
\end{itemize}
