\chapter{Randomized Algorithms}
\label{ch:randomized}

Randomness buys simplicity and, sometimes, speed. This chapter collects the
probabilistic toolbox, distinguishes the flavours of randomized algorithm, and
then does the two things the course asks of you: solving $2$-list colouring
exactly, and using it inside a randomized $O(1.5^n)$ algorithm for
$3$-colouring.

\section*{Learning goals}
\addcontentsline{toc}{section}{Learning goals}

After this chapter you should be able to:
\begin{itemize}[leftmargin=*]
  \item use Markov's and Chernoff's inequalities and the union bound;
  \item distinguish Monte Carlo and Las Vegas algorithms and one- from two-sided error;
  \item explain constant one-sided error and amplify it by repetition;
  \item define \lang{2-List Coloring} and solve it in polynomial time;
  \item give a randomized constant one-sided error algorithm for \lang{3-Coloring} with running time $O(1.5^n)$.
\end{itemize}
