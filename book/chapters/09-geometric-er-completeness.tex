\chapter{\texorpdfstring{Geometric $\ER$-Completeness}{Geometric exists-R-Completeness}}
\label{ch:geometric-er}

With \textsc{ETR-AM} in hand we can prove $\ER$-completeness for problems that
mention no logic at all. The tools are geometric: point--line duality lets us
move between incidence statements about points and about lines, and geometric
intersection graphs let us hide arbitrary algebraic constraints inside an
innocent-looking graph recognition problem.

\section*{Learning goals}
\addcontentsline{toc}{section}{Learning goals}

After this chapter you should be able to:
\begin{itemize}[leftmargin=*]
  \item describe point--line duality and prove the above--below property;
  \item define the cyclic order of a point with respect to a point set and identify its dual;
  \item define geometric intersection graphs and unit disk graphs;
  \item prove that recognising unit disk graphs is $\ER$-complete;
  \item prove that \textsc{Optimal Curve Straightening} is $\ER$-complete.
\end{itemize}
