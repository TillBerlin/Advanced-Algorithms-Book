\chapter[Exact Algorithms II: Inclusion--Exclusion]{Exact Exponential-Time Algorithms II: Subsets, Inclusion--Exclusion, and Lower Bounds}
\label{ch:exact-ii}

Branching is not the only way to spend an exponential budget. Dynamic
programming over subsets gives $\Ostar(2^n)$ for problems where the obvious
algorithm is $n!$, and inclusion--exclusion often gives the same running time in
polynomial space. We close by asking how much better one could hope to do, which
is where the Exponential Time Hypothesis comes in.

\section*{Learning goals}
\addcontentsline{toc}{section}{Learning goals}

After this chapter you should be able to:
\begin{itemize}[leftmargin=*]
  \item design dynamic programming algorithms over subsets and analyse their time and space;
  \item solve \textsc{TSP} in $\Ostar(2^n)$ time by the Held--Karp algorithm;
  \item state the inclusion--exclusion principle and use it to trade space for time;
  \item count minimum set covers in $\Ostar(2^m)$ time and polynomial space;
  \item state ETH and SETH and derive conditional lower bounds from them.
\end{itemize}
