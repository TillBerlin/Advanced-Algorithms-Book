\chapter{Combinatorics via Algorithms and Stable Marriage}
\label{ch:stable-marriage}

Many combinatorial theorems are most cleanly proved by exhibiting an algorithm
and arguing that it terminates with the desired object. This chapter develops
that idea on two examples: Euler tours, where an algorithm proves a classical
characterisation, and stable matchings, where the Gale--Shapley algorithm proves
that a stable matching always exists.

\section*{Learning goals}
\addcontentsline{toc}{section}{Learning goals}

After this chapter you should be able to:
\begin{itemize}[leftmargin=*]
  \item define an Euler tour and prove that a connected graph has one if and only if every degree is even;
  \item define the stable marriage problem, blocking pairs and stable matchings;
  \item state the greedy algorithm and show that it need not terminate;
  \item state the Gale--Shapley algorithm and prove that it returns a stable matching;
  \item define a men-optimal stable matching and prove that Gale--Shapley computes one.
\end{itemize}
